# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or pull request.

- Use GitHub's private vulnerability reporting for this repository: https://github.com/Ptyktos/framefold/security/advisories/new
- Or email the security team at security@twn.systems.

Include a description of the problem, the affected version or commit, steps to reproduce, and the impact as you understand it.

## Supported versions

framefold is pre-release (0.x). Only the latest commit on the default branch is supported.

## Response

We aim to acknowledge a report within 5 working days. The response time for fixes is not yet set.

## Scope

framefold parses HTML, CSS and fonts from compositions and runs their timeline scripts. Reports about malformed compositions, fonts or scripts that crash, hang or exhaust memory are in scope.
